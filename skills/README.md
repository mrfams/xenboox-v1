# Skills Directory

> **Deprecated:** These flat `.md` skills are superseded by the standard SKILL.md format in `.agents/skills/`.

The `.agents/skills/` directory contains the canonical skill files with proper YAML frontmatter, compatible with Claude Code, OpenCode, Codex CLI, Gemini CLI, and other agents that support the Agent Skills standard.

For installable external skills (gstack, mattpocock, anthropic), see `scripts/setup-skills.ps1`.
