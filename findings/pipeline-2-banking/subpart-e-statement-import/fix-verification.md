**Behavior now:**

- Corrupted/garbage statement → job fails, document status `failed`, user sees the deterministic reason(s), audit-logged, DLQ'd, no rows written.
- Debits-as-positive CSVs import with correct direction (balance-delta inference).
- Balance-less statements warn that nothing was cross-validated; running-balance corruption >10% blocks.
- Legitimately repeated references with different amounts no longer dropped.
- Every statement-import warning reaches the user in the UI.

**Not touched (scope):** OCR pipeline internals (`lib/ocr.ts`) — audited as solid in P2-C; CSV/PDF parse heuristics beyond the fixes above; other pipelines.
