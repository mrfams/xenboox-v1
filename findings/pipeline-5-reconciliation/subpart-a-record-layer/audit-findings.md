# P5-A — Bank Reconciliation: Record/Linking Layer — Audit & Fixes

## Findings

| #      | Severity     | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Fix                                                                                                                                                                                                                                                                                                                                                                |
| ------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **A1** | **Critical** | **Two competing reconciliation routers.** `_app.ts` mounts the standalone `reconciliation.ts` router (procedures: `getReconciliationCenter`, `matchTransaction`, …), but `banking.ts` ALSO exported a `reconciliationRouter` (`getReconciliationData`, `getAiMatches`, `reconcileTransaction`, `unreconcileTransaction`) that was **never mounted**. The UI (`reconciliation-view.tsx`) calls the banking.ts names → **tRPC "No procedure found" on every load**. Reconciliation as a feature had **no working user path** (the view wasn't imported anywhere). | Merged the four UI-facing procedures into the **mounted** `reconciliation.ts` router (production-grade, below) and **deleted the dead block from banking.ts** (360 lines, plus its now-unused `reconciliations` import).                                                                                                                                           |
| **A2** | **Critical** | `reconcileTransaction` linked **any** `journalEntryId` with zero validation — no existence check, no entity scope (a cross-tenant JE id was stored on the transaction), no posted-status check.                                                                                                                                                                                                                                                                                                                                                                 | Rewritten: 404 on missing tx; JE must exist, be **entity-scoped**, and be **posted** ("Only posted journal entries can be reconciled").                                                                                                                                                                                                                            |
| **A3** | **Critical** | `reconcileTransaction` updated `journalEntries.bankTransactionId` via an `as any` cast — **that column does not exist in the schema** (verified) → the update 500'd on every reconcile.                                                                                                                                                                                                                                                                                                                                                                         | Removed the phantom update entirely (the tx-side link + audit trail is the record).                                                                                                                                                                                                                                                                                |
| **A4** | High         | `reconcileTransaction` silently **overwrote an existing link**, re-pointing a posted transaction to a different JE (breaks the P2 ledger-lock).                                                                                                                                                                                                                                                                                                                                                                                                                 | Blocked: "Transaction is already linked to another journal entry — unreconcile it first" (same-JE re-reconcile is an idempotent no-op).                                                                                                                                                                                                                            |
| **A5** | Medium       | Matching had **no audit trail**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `reconcileTransaction` / `unreconcileTransaction` now write `auditLog` entries (before/after link).                                                                                                                                                                                                                                                                |
| **A6** | Medium       | Raw string ids accepted by mutations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `bankTransactionId`/`journalEntryId` now `z.string().uuid()`.                                                                                                                                                                                                                                                                                                      |
| **A7** | Medium       | **View was orphaned** — no user could reach reconciliation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Mounted `<ReconciliationView />` as a **"Reconcile" tab in the Operations → Banking surface** (5-surface model preserved; no new sidebar page). ⚠️ _Needs review: I chose the Banking tab over the Ledger page (whose comment says reconciliation is agent-workflow-only). If you'd rather it live in Ledger or behind the AI chat only, say so and I'll move it._ |
| **A8** | Medium       | `getReconciliationCenter` book-vs-statement math compared a **period transaction sum against the bank's current balance** (apples-to-oranges) and `finalizeReconciliation` recorded `bookBalance = account.currentBalance` (bank-side, not GL-side).                                                                                                                                                                                                                                                                                                            | Deferred to P5-C (GL integrity) where the GL account link (`bankAccounts.glAccountId`) makes the honest book balance computable.                                                                                                                                                                                                                                   |
