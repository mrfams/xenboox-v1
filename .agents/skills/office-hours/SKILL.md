Run a structured product interrogation using these 6 forcing questions. Answer each rigorously before writing any code.

## The 6 Questions

### 1. Who is this for?

Name the specific user persona. Not "users" — a named type. Example: "Sarah, a finance director at a 50-person NGO in Banjul."

### 2. What job does it do for them?

What outcome changes for them? Not features — outcome. "Sarah can close the month in 2 hours instead of 3 days."

### 3. Why now?

What changed in the market, technology, or user behavior that makes this urgent?

### 4. What's the 10x version?

If this worked perfectly, what would it look like? Not incremental — 10x.

### 5. What's the simplest possible version that delivers the core job?

Strip to essentials. What's the smallest thing you can build that still delivers the outcome?

### 6. How do we know if it's working?

One metric. North star. What number goes up when this succeeds?

## Process

1. Present each question one at a time
2. Wait for a complete answer before moving to the next
3. Challenge vague answers: "Can you be more specific?"
4. If an answer contradicts a previous answer, flag the inconsistency
5. After all 6, write a 3-sentence product brief synthesizing the answers
