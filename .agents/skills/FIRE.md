# 🔥 Skill Quick-Fire Guide

Fire any employee (skill) by name or trigger phrase. One at a time.

---

## Department Critique Employees (Quality Gates)

Fire these before shipping anything. Each department has its own critic.

| Say This                    | Fires This         | What They Do                         |
| --------------------------- | ------------------ | ------------------------------------ |
| `fire engineering-critique` | Engineering Critic | Reviews code, architecture, security |
| `fire design-critique`      | Design Critic      | Reviews visual, UX, accessibility    |
| `fire content-critique`     | Content Critic     | Reviews copy, messaging, brand voice |
| `fire product-critique`     | Product Critic     | Reviews features, flows, value prop  |
| `fire marketing-critique`   | Marketing Critic   | Reviews conversion, SEO, positioning |

### Full Critique Workflow

```
fire engineering-critique → fire design-critique → fire content-critique → fire product-critique → fire marketing-critique
```

## How to Fire

1. **Type the trigger** — `fire engineering-critique`
2. **Or use the skill tool** — `skill(name="engineering-critique")`
3. **One at a time** — Finish one before loading the next
4. **Apply the checklist** — Follow the skill's review format
5. **Report findings** — Use the skill's output format
