### Financial Philosophy

**Data-Driven Decisions:**

- Every decision has financial implications
- Measure twice, cut once
- Cash is king
- Profitability > growth (at scale)

**Simplicity in Complexity:**

- Break down complex problems
- Use clear metrics
- Avoid jargon
- Tell the story with numbers

### Key Financial Metrics

**Revenue Metrics:**

- **MRR/ARR**: Monthly/Annual Recurring Revenue
- **ARPU**: Average Revenue Per User
- **ACV**: Annual Contract Value
- **Expansion Revenue**: Upsells and cross-sells

**Growth Metrics:**

- **MoM Growth**: Month-over-month revenue growth
- **YoY Growth**: Year-over-year revenue growth
- **Net Revenue Retention**: Revenue from existing customers
- **Gross Churn**: Revenue lost from existing customers

**Efficiency Metrics:**

- **CAC**: Customer Acquisition Cost
- **LTV**: Customer Lifetime Value
- **LTV/CAC Ratio**: Target > 3
- **Payback Period**: Months to recover CAC

**Unit Economics:**

- **Gross Margin**: Revenue - COGS
- **Contribution Margin**: Revenue - Variable Costs
- **Burn Rate**: Monthly cash consumption
- **Runway**: Months until cash runs out

### Financial Modeling

**Revenue Model:**

```
Revenue = Users × ARPU × (1 - Churn Rate)

Where:
- Users = Previous Month Users + New Users - Churned Users
- ARPU = Average Revenue Per User
- Churn Rate = % of users who cancel
```

**Cost Model:**

```
Total Costs = Fixed Costs + Variable Costs

Fixed Costs:
- Salaries
- Rent
- Software subscriptions
- Insurance

Variable Costs:
- Hosting (scales with usage)
- API costs (scales with usage)
- Payment processing (% of revenue)
- Support (scales with customers)
```

**Profitability Model:**

```
Profit = Revenue - Total Costs

Break-Even Point:
Fixed Costs / (Price - Variable Cost per Unit)
```

### Forecasting Methods

**Bottom-Up:**

- Start with unit economics
- Project user growth
- Calculate revenue
- Add cost projections

**Top-Down:**

- Start with market size
- Estimate market share
- Calculate revenue potential
- Validate with unit economics

**Scenario Analysis:**

- **Base Case**: Expected outcome
- **Best Case**: Optimistic scenario
- **Worst Case**: Conservative scenario
- **Stress Test**: Extreme conditions
