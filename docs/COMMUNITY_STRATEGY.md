# Community Strategy

> Building a community of Xenboox users and partners in The Gambia.

---

## Platform Choice

**Primary:** Slack (professional audience, familiar to business users)
**Secondary:** WhatsApp Group (widespread in The Gambia, low barrier)

---

## Community Structure

### Slack Channels

| Channel           | Purpose                    | Moderation      |
| ----------------- | -------------------------- | --------------- |
| #general          | Announcements, updates     | Admin           |
| #product-feedback | Feature requests, bugs     | Admin + Support |
| #accounting-tips  | Best practices, guides     | Admin           |
| #partners         | Partner program discussion | Admin           |
| #off-topic        | Community building         | Self-moderated  |

### WhatsApp Group

- Weekly product updates
- Quick questions and answers
- Event announcements
- Success stories

---

## Launch Plan

### Phase 1: Seed (Month 1-2)

- [ ] Create Slack workspace
- [ ] Invite 20 beta users
- [ ] Post daily accounting tips
- [ ] Host weekly Q&A session
- [ ] Gather feedback on product

### Phase 2: Grow (Month 3-6)

- [ ] Open community to all users
- [ ] Launch WhatsApp group
- [ ] Host monthly webinar
- [ ] Create community guidelines
- [ ] Appoint community champions

### Phase 3: Scale (Month 7-12)

- [ ] Reach 500 members
- [ ] Launch partner directory
- [ ] Host quarterly meetup
- [ ] Create user-generated content program
- [ ] Community-driven feature voting

## Community Guidelines

1. **Be respectful** — Treat everyone with dignity
2. **Be helpful** — Answer questions when you can
3. **Be constructive** — Criticism is welcome, but be specific
4. **No spam** — No promotions without admin approval
5. **No financial advice** — Share knowledge, not recommendations
