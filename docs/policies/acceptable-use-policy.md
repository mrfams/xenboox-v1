# Acceptable Use Policy

> Xenboox — AI-Native Accounting Platform
> Effective Date: September 2026
> Version: 1.0
> Owner: Security Officer

---

## 1. Purpose

This policy defines acceptable use of Xenboox's information systems, networks, data, and resources. All users must comply with this policy.

## 2. Scope

Applies to all employees, contractors, and third parties with access to Xenboox systems.

## 3. Acceptable Use

### 3.1 Systems and Networks

- Use company systems for authorized business purposes
- Keep systems updated with security patches
- Lock workstations when unattended
- Use strong, unique passwords for all accounts
- Report security incidents immediately

### 3.2 Data Handling

- Access only data necessary for your role (least privilege)
- Never share credentials or access tokens
- Never store sensitive data in unapproved locations (personal drives, unencrypted USB)
- Encrypt sensitive data before transmission
- Follow data classification guidelines

### 3.3 Email and Communication

- Do not open attachments from unknown senders
- Verify sender identity before acting on sensitive requests
- Do not share customer data via unapproved channels
- Use company email for business communications

### 3.4 Software and Tools

- Use only approved software and tools
- Do not install unauthorized software on company devices
- Do not use personal accounts for company work (shadow IT)
- Keep development dependencies updated

## 4. Prohibited Activities

- Unauthorized access to systems or data
- Sharing credentials or authentication tokens
- Installing malware or unauthorized software
- Circumventing security controls (rate limiting, access controls, encryption)
- Using company resources for personal financial gain
- Storing customer data in personal accounts or devices
- Disabling security features (MFA, logging, monitoring)
- Reverse engineering proprietary code or systems

## 5. Monitoring

- Company systems may be monitored for security purposes
- Audit logs are maintained for all system access
- Monitoring includes: access logs, data access patterns, network traffic
- Users have no expectation of privacy on company systems

## 6. Enforcement

- Violations may result in disciplinary action up to termination
- Security incidents will be investigated per the Incident Response Plan
- Repeat violations result in immediate access revocation
