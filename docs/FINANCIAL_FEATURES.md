# Financial Features Roadmap

> Advanced financial features for Xenboox.

---

## Comparative Financial Reporting

### "vs Last Month" Columns

- Side-by-side comparison of current vs previous period
- Percentage change indicators
- Variance highlighting for significant changes

### "vs Budget" Columns

- Compare actuals to budget amounts
- Budget utilization percentages
- Alert when over budget

---

## Proactive Budget Alerts

### Threshold-Based Alerts

| Alert Type         | Trigger                   | Action         |
| ------------------ | ------------------------- | -------------- |
| Over budget        | Actual > 100% of budget   | Email + in-app |
| Approaching budget | Actual > 80% of budget    | In-app only    |
| Unusual spending   | 2x average daily spend    | Email          |
| Revenue shortfall  | Revenue < 80% of forecast | Email          |
