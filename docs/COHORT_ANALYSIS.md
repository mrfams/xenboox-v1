# Cohort Analysis

> Grouping users by signup month to track retention, activation, and revenue trends.

---

## What is Cohort Analysis?

A cohort is a group of users who signed up in the same time period (usually the same month). By tracking each cohort independently, we can see whether the product is getting better over time.

## How to Use Cohort Analysis

### Identify Improvement

If Month 3 cohorts have better D30 retention than Month 2, our changes are working.

### Identify Problems

If a specific cohort has unusually high churn, investigate what happened (pricing change, bug, competitor launch).

### Predict Revenue

Use cohort retention curves to forecast future MRR from existing users.

## SQL Query

```sql
WITH cohorts AS (
  SELECT
    user_id,
    DATE_TRUNC('month', created_at) AS cohort_month
  FROM users
),
activity AS (
  SELECT
    user_id,
    DATE_TRUNC('month', last_active_at) AS activity_month
  FROM users
)
SELECT
  c.cohort_month,
  COUNT(DISTINCT c.user_id) AS cohort_size,
  COUNT(DISTINCT CASE WHEN a.activity_month = c.cohort_month THEN c.user_id END) AS month_0,
  COUNT(DISTINCT CASE WHEN a.activity_month = c.cohort_month + INTERVAL '1 month' THEN c.user_id END) AS month_1,
  COUNT(DISTINCT CASE WHEN a.activity_month = c.cohort_month + INTERVAL '2 months' THEN c.user_id END) AS month_2
FROM cohorts c
LEFT JOIN activity a ON c.user_id = a.user_id
GROUP BY 1
ORDER BY 1;
```
