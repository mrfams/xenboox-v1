# Support System

> Customer support channels and processes for Xenboox.

---

## Support Channels

| Channel     | Priority   | SLA         | Tool                |
| ----------- | ---------- | ----------- | ------------------- |
| In-app chat | High       | < 4 hours   | Intercom/Crisp      |
| Email       | Medium     | < 24 hours  | support@xenboox.com |
| Help docs   | Self-serve | Immediate   | /docs               |
| Community   | Peer       | Best effort | Slack/WhatsApp      |

---

## Support Tiers

| Plan     | Channels            | Response Time | Dedicated Support |
| -------- | ------------------- | ------------- | ----------------- |
| Free     | Docs + Community    | Best effort   | No                |
| Starter  | Email + Docs        | 24 hours      | No                |
| Business | Chat + Email + Docs | 4 hours       | Yes               |

---

## Common Issues (FAQ)

| Issue                   | Resolution                                |
| ----------------------- | ----------------------------------------- |
| Can't log in            | Check email/password, try password reset  |
| Bank connection failed  | Re-authenticate, check credentials        |
| AI categorization wrong | Correct manually, AI learns from feedback |
| Export not working      | Check file size, try again                |
| Slow performance        | Check internet, clear cache               |

---

## Escalation Path

1. **L1:** Support agent resolves common issues
2. **L2:** Engineering escalates for bugs
3. **L3:** Founder escalates for critical issues
