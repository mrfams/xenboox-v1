# Win/Loss Tracking

> Understanding why prospects choose Xenboox or go with alternatives.

---

## Definitions

| Outcome                | Definition                                         |
| ---------------------- | -------------------------------------------------- |
| **Win**                | Prospect signed up and upgraded to paid plan       |
| **Loss — Competitor**  | Prospect chose QuickBooks, Xero, or other software |
| **Loss — DIY**         | Prospect decided to keep using spreadsheets/manual |
| **Loss — Budget**      | Prospect couldn't afford the plan                  |
| **Loss — Timing**      | Prospect wasn't ready to switch                    |
| **Loss — Feature Gap** | Prospect needed a feature Xenboox doesn't have     |
| **Loss — Other**       | Prospect went with unknown alternative             |

---

## Data Collection

### Automated (PostHog)

- Track signup source and conversion path
- Monitor feature usage before churn
- Capture pricing page views and plan selection

### Manual (Sales/Support)

- Ask churned users why they left (churn interview)
- Ask lost prospects why they didn't convert
- Log reasons in CRM/Notion
