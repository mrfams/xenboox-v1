## Session: Sign-in + tRPC Middleware Overhaul (2026-08-07)

### Root causes fixed (all verified in browser against production build)

1. **setRlsContext double-quote bug** — `JSON.stringify(userId)` produced `"uuid"` which Postgres parsed as an identifier, not a literal. Fixed with proper single-quote escaping (`sqlLiteral`).
2. **queryCacheMiddleware early-return broke tRPC v11 batch protocol** — middleware returned `{ result: { data }, ctx }` on cache hits without calling `next()`, corrupting batched responses (notifications.list, unreadCount, branding.checkAccess all 500'd on 2nd request). **Removed entirely** — client-side React Query caching already handles dedup.
3. **NEXTAUTH_URL placeholder in .env** — literal `[SENSITIVE]` placeholder broke NextAuth's URL parser → `TypeError: Invalid URL` in `auth()` → 500s. Fixed to `http://localhost:3000`.
4. **Entity resolution chicken-and-egg** — demo user had NULL `last_used_entity_id`; `listUserEntities` was entity-scoped (couldn't list entities to select one). Fixed: jwt callback resolves first entity, listUserEntities → authProcedure, EntityProvider waits for session + auto-selects.
5. **closeCenter.getOverview invalid SQL** — `sql\`${startDate} <= ${period}-28\``produced`2026-08-28` arithmetic garbage. Fixed with proper YYYY-MM-DD boundary strings.
6. **chartOfAccounts.getOverview self-join** — `innerJoin(journalEntryLines, ...)` on identical alias produced invalid SQL. Removed pointless join.
7. **dashboard arOutstanding enum mismatch** — queried `IN ('sent','viewed','overdue')` but `ar_status` enum only has pending/partial/paid/overdue/voided. Fixed to valid values.
8. **Pre-entity query race** — sidebars/top-nav/work/agents fired entity-scoped queries before EntityProvider resolved. All gated with `enabled: isLoaded && !!entityId`.

### Verification

- Production build passes (`next build` ✓), typecheck clean.
- Browser E2E: login → /dashboard OK, then 25 dashboard routes → **0 tRPC errors** across all routes.
